# 桥梁巡检无人机航线规划工具

## 目录结构

```text
assets/models/       内置无人机与示例三维模型
docs/                技术指南与约束文档
examples/pointclouds/ 示例点云
examples/routes/     示例航线 JSON
scripts/             数据转换、建模和辅助下载工具
```

运行所需的 `background.png`、`icon.png`、`icon.ico` 与 `lena.png` 保留在根目录，便于运行和 PyInstaller 打包。

## 安装依赖

```bash
pip install -r requirements.txt
```

依赖包：
- `PyQt5 >= 5.15` — GUI 框架
- `numpy >= 1.20` — 数值计算
- `vtk >= 9.0` — 3D 可视化

## 运行

```bash
python main.py
```

```bash
pip install pyinstaller
pyinstaller --onedir --windowed --name "BridgeRoutePlanner" main.py
```

## 功能说明

### 1. 加载点云
- 点击 **"打开 PCD 文件"** 加载 `.pcd` 格式点云
- 支持 ASCII 和 Binary 格式的 PCD 文件
- 点云加载后自动根据范围填充默认航线参数

### 2. 平面航线（桥底面弓字形扫描）
- 设置扫描区域 X/Y 范围、飞行高度、行间距、速度
- 生成弓字形（蛇形）航线，适用于桥底面巡检

### 3. 立方体航线（桥柱环绕扫描）
- 设置柱体中心坐标、尺寸、离柱面距离、步长
- **螺旋线**：绕柱体螺旋上升扫描
- **Z字形**：逐层上下扫描

### 4. 航线管理
- **保存航线**：导出为 JSON 格式，包含位置、四元数、速度
- **加载航线**：从 JSON 文件恢复航线
- **清除航线**：清除当前航线（保留点云）

### 5. 拍摄范围计算器

通过 **设置 → 拍摄范围计算器** 打开。选择相机型号，调整光学变焦、数码变焦及目标距离后，界面会自动更新当前焦距、水平视场角（FOV）和拍摄范围。

#### 代码位置

- `main_window.py` 的 `_show_range_calculator_dialog()`：创建计算器界面；菜单通过 `_act_range_calc` 连接到此函数。
- 对话框内的 `calculate()`：执行全部计算并更新显示。
- `self._camera_fov_map`：相机型号对应的基准水平 FOV，单位为度。
- 对话框内的 `camera_focal_range`：相机型号对应的基准焦距和最大光学变焦倍数。

这些参数来自代码中的预设表，不是运行时从相机读取。光学变焦滑块以 0.1 倍为步长，其上限由所选型号的预设值决定。

#### 计算过程

采用正对目标平面的视场几何模型，不涉及点云或三维模型求交。设：

| 符号 | 含义 | 单位 |
|------|------|------|
| `θ₀` | 所选相机的基准水平 FOV | 度 |
| `f₀` | 所选相机的基准焦距 | mm |
| `Zₒ` | 光学变焦倍数，相对于所选镜头的基准 | 无量纲 |
| `Zᵈ` | 数码变焦倍数 | 无量纲 |
| `D` | 相机到目标平面的距离，正对平面时沿光轴测量 | m |

正常计算应使用正的距离和变焦倍数。以下三角函数公式中的角度按数学记法表示；Python 的 `math.tan()` 接收弧度，因此代码使用 `math.radians()` 转换角度，使用 `math.degrees()` 将反三角函数结果转回度。

1. **反推等效尺寸 `S`**：根据基准焦距和水平 FOV 计算水平方向的等效尺寸。

   ```text
   S = 2 × f₀ × tan(θ₀ / 2)
   ```

2. **计算总变焦和当前焦距 `f`**：数码变焦按等效裁剪处理，参与视场计算；这里的“当前焦距”并不表示数码变焦改变了镜头的物理焦距。

   ```text
   Z = Zₒ × Zᵈ
   f = f₀ × Z
   ```

3. **计算变焦后的水平 FOV `θ`**：

   ```text
   θ = 2 × atan(S / (2 × f))
   ```

4. **计算目标平面的水平覆盖宽度 `W`**：

   ```text
   W = 2 × D × tan(θ / 2)
   ```

将上述步骤合并，在正的变焦倍数下可简化为：

```text
W = 2 × D × tan(θ₀ / 2) / (Zₒ × Zᵈ)
```

因此，在相机型号和变焦不变时，覆盖宽度与目标距离成正比；在距离不变时，覆盖宽度与总变焦倍数成反比。

#### 计算示例

选择 **M4T 中长焦**：预设基准焦距为 `72 mm`，水平 FOV 为 `20.8°`。目标距离设为 `3 m`，计算器内光学变焦、数码变焦均为 `1.0`：

```text
Z = 1 × 1 = 1
f = 72 × 1 = 72 mm
θ = 20.8°
W = 2 × 3 × tan(10.4°) ≈ 1.10 m
```

若仅将数码变焦改为 `2.0`，水平覆盖宽度约为 `0.55 m`。这里的 `1.0` 倍以所选中长焦镜头为基准，不是相对于 M4T 广角镜头；不应再额外乘一次相机设置中的默认 3 倍变焦。

#### 当前实现的限制

- **显示的宽、高实际使用同一个数值**：`calculate()` 通过 `range_size × range_size` 输出结果，没有根据画幅比例单独计算高度。因此上例显示为 `1.1 m × 1.1 m`，不能理解为真实矩形画幅的宽和高。若按 4:3 画幅换算，覆盖应约为宽 `1.10 m`、高 `0.83 m`。
- **尺寸注释与计算方向不一致**：源码把 `sensor_size` 注释为“传感器对角线”，但计算输入是水平 FOV，因此它实际是用于水平视场换算的等效尺寸，不能直接当作真实传感器对角线。
- **计算器未使用画幅比例**：项目另有 `_vertical_fov()` 根据水平 FOV 和 `self._camera_aspect` 计算垂直 FOV，但本对话框没有调用它。
- **“当前相机”按钮只选择型号**：不会同步无人机参数中的变焦倍数或自定义 FOV；本计算器仍使用自己的变焦输入和预设 FOV 表。
- **仅提供理想几何估算**：不考虑目标倾斜、表面起伏、遮挡或镜头畸变，也不计算像素分辨率、地面采样距离（GSD）或航线重叠率。数码变焦缩小覆盖范围不代表增加实际光学细节。

## JSON 航线格式

```json
{
  "version": "1.0",
  "description": "桥梁巡检航线",
  "waypoint_count": 100,
  "waypoints": [
    {
      "position": { "x": 1.234, "y": 5.678, "z": 10.0 },
      "quaternion": { "w": 1.0, "x": 0.0, "y": 0.0, "z": 0.0 },
      "speed": 3.0,
      "action": "fly"
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `position` | object | 航点三维坐标 (米) |
| `quaternion` | object | 姿态四元数 (w, x, y, z)，描述无人机朝向 |
| `speed` | float | 飞行速度 (m/s) |
| `action` | string | 动作类型: `fly`(飞行) / `scan`(扫描) |

### 坐标系说明

- 界面展示使用**地图坐标系**（方便预览）
- 导出 JSON 中的四元数使用**雷达 IMU 坐标系**（供飞控使用）
- 转换公式：`R_lidar = inv(airy_lidar_to_airy_imu_R) @ R_map`
- 外参矩阵 `airy_lidar_to_airy_imu_R` 硬编码在 `quaternion_utils.py` 中
